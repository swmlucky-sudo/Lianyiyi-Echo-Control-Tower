*An Entry for Gemini 3 Hackathon 2026*

## 🛠️ Technical Implementation

### 1. **Cadence-Based Reasoning (流速感知推理)**
Unlike static LLM interfaces, Lianyiyi Echo calculates the user's **Input Velocity (Chars/Sec)**. 
* **High Velocity**: Triggers `TW_SAW` mode for rapid decision convergence.
* **Low Velocity**: Triggers `JP_SIN` mode for deep reflective analysis.

### 2. **Phonetic Accent Scanning (重音掃描)**
Using **Gemini 3 Flash's** advanced reasoning, the system identifies the "stress peaks" in the text, mapping them to phase shifts in the simulated **Phase-Locked Loop (PLL)**.

### 3. **The 440Hz Consensus (440Hz 終極定音)**
All heterogeneous inputs are eventually normalized to a stable **440Hz** output, symbolizing the achievement of a "Reasoning Lock" across different cultures and languages.

## 🚀 Getting Started

### Prerequisites
* A valid **Gemini API Key** from [Google AI Studio](https://aistudio.google.com/app/apikey).
* A modern browser supporting ES6+.

### Setup
1. Clone this repository (**Private setting recommended**).
2. Open `index.html`.
3. Locate `const GEMINI_API_KEY = "";` and insert your key.
4. Launch the file in your browser to enter the **Audit Tower**.
